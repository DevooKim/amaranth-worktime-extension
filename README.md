# gw-worktime

아마란스 그룹웨어(`gw.goorm.io`)에 들어가지 않고, 크롬 팝업에서 이번 달 근무시간과
오늘 근무 시간과 퇴근 가능 시각을 확인하는 비공식 확장.

## 설치

1. 크롬에서 `chrome://extensions` 열기
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더 선택
4. 그룹웨어(`https://gw.goorm.io`)에 **한 번** 접속 — 사번을 읽어 저장한다
5. 툴바의 시계 아이콘 클릭

4번은 최초 1회만 필요하다. 그 뒤로는 그룹웨어에 들어가지 않아도 된다.

## 화면

**[오늘]**
오늘 근무 시간(클릭하면 부족한 시간으로 전환, 아래에 퇴근 가능 시각 표시), 이번 달 진행률,
오늘 남은 시간(하루 8시간 기준), 이번 달 초과·부족 누적,
남은 근무일(남은/전체), 퇴근 미등록 경고

**[기록]**
월 달력. 앞뒤 달로 넘길 수 있다. 칸을 누르면 그날의 출퇴근과 인정 근무시간이 아래에 뜬다.

| 표시 | 뜻 |
|---|---|
| 블루 농도 | 그날 근무시간. 진할수록 오래 일한 날 |
| 오렌지 칸 + `연차` | 종일 휴가 (칸 전체가 찬다) |
| 아래 절반 오렌지 + `반차` | 반차. 반반차는 아래 1/4만 찬다 |
| 붉은 칸 + `미등록` | 출근만 찍고 퇴근을 안 찍은 날 |
| 붉은 날짜 + 이름 | 일요일·공휴일 (`추석`, `대체휴일`) |
| 블루 테두리 | 오늘 |

칸은 실제 `button`이라 키보드로도 넘길 수 있고, 선택 상태가 `aria-pressed`로 노출된다.

달력 아래에 근무일 수가 어떻게 나왔는지 함께 적는다 — `근무일 20일 — 평일 22일 − 공휴일 2일`.
휴가는 근태캘린더에서 가져오므로 **앞으로 예정된 휴가도** 보인다.

**남은 연차**는 [오늘] 탭 아래쪽과 [기록] 탭 휴가 목록 옆에 나온다.
일반 연차와 보상 휴가(대체 휴가가 있으면 그것도)를 나눠서 보여준다 —
`연차 9.5 · 보상 2.4`. 그룹웨어 값을 그대로 쓰므로 소수점까지 맞다.

**[설정]** 적용된 근무규칙, 하루 근무시간 변경, 연결 진단, 사번 직접 입력

하단 **↻ 새로고침**은 캐시를 버리고 서버에서 다시 가져온다.
평소에는 팝업을 열 때마다 갱신되고, 일자별 기록·공휴일·휴가는 30분 캐시된다.

다른 날 소정보다 더 일한 시간은 자동으로 오늘 목표에서 빠진다.
"이번 달 초과·부족"이 그 적립분이다.

**[알림]**
그룹웨어 알림 목록. 안 읽은 알림은 진한 글씨와 파란 점으로 표시된다.
제목을 누르면 상세가 새 창으로 열리고 읽음 처리된다. 점만 누르면 창을 열지 않고 읽음 처리한다.

백그라운드에서 3분마다 새 알림을 확인해 데스크톱 알림으로 띄우고,
안 읽은 알림이 있으면 툴바 아이콘에 빨간 점을 올린다. 데스크톱 알림을 누르면 상세가 열린다.
설치 직후 첫 확인은 기준선만 잡고 알림을 띄우지 않는다.

## 단축키

| 키 | 동작 |
|---|---|
| `Alt+Shift+F` | 팝업 열기 |
| `Alt+Shift+E` | 오늘 → 기록 → 알림 탭 전환 |
| `Alt+Shift+T` | 오늘 근무 시간 ↔ 부족한 시간 전환 |

사이드패널로도 열 수 있다.

## 디자인

구름 디자인 시스템(Vapor) 토큰 기준. 중립 회색 화면에 블루 강조 하나,
카드는 1px 테두리 + 12px 라운드, 글꼴은 Pretendard Variable(`fonts/`에 내장).

## 동작 방식

그룹웨어 쿠키(`oAuthToken`, `signKey`)를 읽어 요청마다 HMAC 서명을 만들어 API를 호출한다.
비밀번호를 저장하지 않고, 데이터를 외부로 보내지 않는다. 모든 계산은 브라우저 안에서 끝난다.

자세한 설계는 [설계 문서](docs/superpowers/specs/2026-09-01-gw-worktime-extension-design.md)에 있다.

## 테스트

```bash
npm test
```

계산 로직(`lib/calc.js`)만 테스트한다. 네트워크는 타지 않는다.

## 알아둘 것

- 그룹웨어 세션이 만료되면 확장도 동작하지 않는다. 그룹웨어에 다시 로그인해야 한다.
- 퇴근 전에 보이는 오늘 근무시간은 추정치다. 퇴근을 등록하면 서버 확정값으로 바뀐다.
- 비공식 확장이라 그룹웨어가 서명 방식이나 응답 형식을 바꾸면 깨진다.
- 조회 전용이다. 출퇴근 등록 기능은 넣지 않았다.
